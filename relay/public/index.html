02 — Valores

No que acreditamos

Simplicidade

Se você precisou de um manual, nós falhamos. Se o usuário travou, o problema é nosso, não dele.

Acessibilidade

Tecnologia que cabe no bolso de quem precisa. Se só quem pode pagar tem acesso, ainda não está pronta.

Propósito antes da técnica

Não criamos IA para impressionar. Criamos para resolver. Se uma solução simples resolve, solução simples é a resposta.

O palco é de quem usa

A Konectx não aparece na apresentação do professor. Se o produto some durante o uso, fizemos certo.
